# 余额宠物·大肥鱼（pet-buddy）v4.15.0

> 坚祥数字助理的桌宠插件：**桌宠常驻 + 傲娇聊天 + 余额显示 + 语音/音效 + 模型管理**五合一。
> 全程离线可用（合成与识别都在本机），零第三方依赖，装完刷新即用。

---

## 一、它能做什么

| 能力 | 怎么用 |
|---|---|
| **桌宠常驻** | 可拖拽、拖到边缘自动吸附、位置记忆、隐藏/恢复；5 套皮肤可选（官方精灵图 / 社区桌宠包 / BongoCat 键盘猫 / 和大人 120 帧动画 / RYANFFY 立绘），大小 40–200px 可调；**上传 GIF/动画 WebP 即成会动的皮肤**（静态图 ≤2MB、动图 ≤4MB），空闲时随机做小动作（摆动/跳/歪头） |
| **自行移动** | 桌宠**自己走两步**：默认每 3 分钟（±抖动）溜达一次，模式可选**走走停停**（水平散步）/ **逛桌面**（换位置）/ 不自己动，速度三档；起步节奏讲究——**先原地踏步**（普通动作 0.5s、「左转奔跑」类 1s）**再用 1 秒加速到正常速度**再匀速跑，末段收住；三个行走动作轮着用、向右走镜像；被拖动或戳一下立刻停下 |
| **余额显示** | **单击**：随机一句反应词 +（真实余额）。数据优先取助手内部通道额度（月度剩余/总额/已用/刷新日），也支持 `sk-` 网关 API Key 账单；三种文案格式（简洁 / 详细 / 傲娇） |
| **聊天** | **双击**就地输入框；右键「气泡聊天」＝屏幕内圆角气泡面板（可拖动、**始终贴着桌宠头顶**、**输入行带 😊 表情面板**：最近/大肥鱼/黄豆/女仆/表情包 67 张/我的，点一张直接发或追加到输入框，「我的」可批量添加图片或 zip）；**双击闲聊的内容会同步进面板**；备用独立聊天窗口；走助手子对话（同一会话，历史互通） |
| **语音播报** | 回复自动念出来。三种模式：**语调引导** / **经典合成** / **普通朗读**（真人声）；可切 bibo 音色、朗读音色、语速、音量；断句明显；**数字转中文读法**（67834 → 六点八万）；**试听文本可自己改**（默认「你好，我是坚祥数字助理！」） |
| **表情包** | 内置 **67 张**且**每张都有语义名**（档案馆 16 + 微信 24 逐张看图命名 + 大肥鱼模型包 27），说人话就能发（如 `[stick:害羞捂脸]`、`[stick:可爱]`）；提示词按情绪/场景教它**什么时候插哪个**；**表情包管理**（设置里）：批量导入图片/zip、导出 zip、点一下复制标记、删除保下标 |
| **语音闲聊** | 按住 **右 Alt + M** 说话，松开就发；也可点菜单开一轮。识别走宿主「语音」组件的本地离线模型（16k 采集 + VAD）。**左 Alt 留给助手自带听写，插件不占用** |
| **交互音效** | 点桌宠「啵」、弹面板「叮」、拖拽吸附「唰」、听写成功「嗯」、出错「哔」；音量可调；**互动形变**可开（点一下像弹簧压一下） |
| **台词可编辑 + AI 生成** | 开场白（支持 `{greet}` `{nickname}`）与戳一戳反应词都能手动编辑；也能让 AI **按人设 + 最近聊天记录**生成，支持每天/每周自动更新 |
| **模型管理** | 上传图片（静态 ≤2MB / 动图 ≤4MB）、**直接上传 zip 模型包**（自动列出包里的图片任你挑）、**整套整合动作包**（`tools/import-petpack.mjs`，把 dsh-pet 格式的包连动作带交互一次搬进来）、导入/导出 `.json` 模型包、改名、移除、**彻底删除**；内置模型也能收起来 |
| **动作包（petpack）** | 内置「大肥鱼·鲸鲸娘（完整动作包）」：**114 个动作**（VP9-alpha 视频，6.5MB）——点击回应、拖动悬空、余额 6 档、80 个随机表演（吃月饼/放烟花/装点圣诞树…）；双缓冲播放不闪白 |
| **成果卡片** | 对话产出的文件（图片/表格/文档…）在气泡聊天里自动认成卡片：**真缩略图预览**（图片/视频）+ 点卡片打开文件 + 「打开 / 定位 / 复制」；单条消息最多 3 张、同路径去重；交付约定只在首轮人设里说一次 |
| **常用语库** | 增删改查 + 点「说」直接念出来 |
| **角色设定 / 思考日志** | 人设可改；思考过程只进后台日志，绝不上屏 |

## 二、装与用

### 安装（三选一）

| 形态 | 适合谁 | 怎么做 |
|---|---|---|
| **单文件安装器 `一键安装-pet-buddy-v4.0.0.cmd`** | 只想收一个文件的人 | **双击即装**（自动找宿主目录、备份旧版、镜像覆盖），不需要管理员/Node/联网 |
| `pet-buddy-v4.0.0-一键安装.zip` | 习惯解压的人 | 解压 → 双击 `安装.cmd`（含 `卸载.cmd`） |
| `pet-buddy-v4.0.0.zip` | 手动部署 / 二次开发 | 解压到 `…\坚祥数字助理GO\插件兼容层\`，目录名 `pet-buddy` |

装完在助手窗口按 **F5** 刷新。卸载：`卸载.cmd` 会把插件目录移到 `%TEMP%\pet-buddy-removed-<时间戳>`。

### 第一分钟上手

1. **点一下桌宠** → 听一声「啵」，气泡里是「反应词（余额）」
2. **双击桌宠** → 就地输入框，说句话，它会回你并且念出来
3. **右键** → 分栏菜单：气泡聊天 / bibo语音 / bibo音效 / 桌宠 / 设置（设置里分**通用 / 聊天 / 声音**三个弹窗）4. **按住右 Alt + M** → 对着它说话

## 三、开发

### 目录结构

```
pet-buddy/
├─ src/
│  ├─ core/              # 共享核心（构建期注入两份产物）
│  │  ├─ config.js       #   版本号唯一来源、默认设置、存储键
│  │  ├─ util.js         #   工具（千分位、tok 简写、时间）
│  │  ├─ store.js        #   设置读写（localStorage）
│  │  ├─ stickers.js     #   贴纸解析与渲染、皮肤表、素材基准探测
│  │  ├─ balance.js      #   价目/谷价、今日消耗、余额文案三格式
│  │  ├─ speech.js       #   语音播报：断句切段 + 三种合成模式
│  │  ├─ sfx.js          #   交互音效（同一套合成器造短音）
│  │  ├─ voiceinput.js   #   语音听写：16k 采集 + VAD + 宿主 ASR
│  │  └─ chat.js         #   三通道发送、人设指纹、提示词组装
│  ├─ pet.client.js      # 桌宠半边源码（注入 core 后 = client.js）
│  └─ chat.template.html # 聊天窗口源码（注入 core 后 = chat.html）
├─ vendor/bibibobo.js    # 第三方合成核心（MIT，构建期原样内联）
├─ build.mjs             # 构建：vendor + core → 两份产物（标记注入，失配即报错）
├─ assets.manifest.json  # 素材清单（60 个：图标/贴纸/皮肤/精灵图），install、pack、smoke 共用
├─ 一键构建并同步.cmd     # 开发机一条命令：build → smoke → install → pack → pack-oneclick
├─ tools/
│  ├─ smoke.mjs          # 离线冒烟自检（不依赖宿主）：253 项断言
│  ├─ install.ps1        # 同步到宿主插件目录（带备份，-WithAssets 连素材）
│  ├─ pack.ps1           # 标准发布包
│  ├─ pack-oneclick.ps1  # 一键安装形态（zip + 单文件 .cmd）
│  └─ oneclick/          # 安装器素材（install-plugin.ps1 / 安装.cmd / 卸载.cmd …）
└─ 素材（必须平铺）        # feiyu-*.png / pet-*.{png,webp} / st-*.webp / ic-*.png / icon.png
```

### 常用命令

```powershell
node tools/smoke.mjs                             # 离线自检（583 项断言）
node build.mjs                                   # 从源码重建产物
node build.mjs --check                           # 产物与源码是否一致（不一致退出码 1）
powershell -File tools\install.ps1 -WithAssets   # 同步到宿主插件目录
powershell -File tools\pack-oneclick.ps1         # 打一键安装形态
```

仓库根双击 **`一键构建并同步.cmd`** 可一次跑完：构建 → 自检 → 同步 → 打三种包。

### 两条硬规则（踩过坑，别再踩）

1. **素材必须平铺在插件根目录**：宿主对 `/_plugins/<id>/` **只服务根级文件**，任何子目录一律 404。
2. **图片路径走 CSS 相对路径或实测基准**：桌面宿主是用 `file://` 或注入方式加载页面的，
   JS 里拼的 `/_plugins/pet-buddy/x.png` 在 file 下会失效。启动时用 `probeAssetBase()` 拿 `icon.png`
   逐个候选试加载，**第一个真的能加载的才算数**，之后所有素材 URL 都基于它。

## 五、验证清单（改完过一遍）

离线：

- `node tools/smoke.mjs` → **583 项全绿**
- `node --check client.js`、`node build.mjs --check`

宿主里（F5 之后）：

1. 桌宠出现、位置与上次一致；拖到边缘吸附；隐藏 → 再右键恢复
1b. **自行移动**：右键 → 桌宠 → 自行移动设置 → 点「**现在就走两步**」：桌宠应**先原地踏步**（「左转奔跑」类会踏 1 秒）→ **再用约 1 秒平稳加速**到正常速度 → 匀速走完 → 收住停下；连点几次能看到三个行走动作轮换。再点菜单里的「自行移动：…」循环到**不自己动**（应不再出发）。默认每 3 分钟自己走一次
2. **单击**：只有**一个**气泡，内容是「反应词（余额）」；连戳 3/5 次时台词与余额仍在同一气泡里
3. **双击**：就地输入框能发消息，回复被念出来；连发两句，前一句被打断（不叠音）
4. **右键菜单**：贴着屏幕右下角打开也不出界；展开子菜单后仍完整可见
5. **气泡聊天**：面板**贴着桌宠头顶**；**点输入行左边的 😊 → 表情面板的格子应是整齐方块（不再堆叠）**，且「大肥鱼」组（挥手/跳/哼/待机…）**张张都有图**；点一张表情：输入框空着就**直接发出去**、有字就追加进去；「我的」里点 ➕ 能加图片或 zip、点「管理」能删
6. **语音**：按住 右 Alt + M 说话 → 先回显「你说：…」再回答；bibo语音里三种朗读模式都能切换出声；数字会念成中文（发「还剩 67834 分」听一耳朵）
7. **模型**：切到和大人应看到动画在动；移除/彻底删除/恢复都正常；切皮肤后形象与点击区对齐（不偏移）；**上传一张 GIF/动画 WebP → 应看到它在动**，等 20~40 秒看它自己摆动/跳一下；**选一个 zip 模型包 → 应列出包里的图片，点一张即可变身**
8. **动作包**：模型面板切到「大肥鱼·鲸鲸娘（完整动作包）」→ 桌宠开始循环呼吸待机；**点一下**换一个点击回应动作；**拖着走**变成被拎起来的动作；**单击看余额**播对应档位动作；等 20~40 秒随机表演一个（吃月饼/放烟花…）；画面**没有黑底**（透明通道正常）
9. **成果卡片**：在气泡聊天里问一个会产出文件的问题（如「画一张我的花费折线图」）→ 回复下方出现卡片（**带图片缩略图**）；**点卡片**应弹出系统程序打开该文件；点「定位」应在资源管理器里选中它；长文件名/长路径应单行省略不折行
9b. **表情包**：设置 → **表情包管理** → 内置应有 **67 张**（往下翻能看到「大肥鱼模型包」那批：Ciallo / 可爱 / 深度睡眠…）；点一张应提示"标记已复制"；**批量导入**选几张图 → 自定义区应出现；**导出全部（zip）** → 应下载一个 zip
9c. **试听文本**：bibo语音 → **试听文本…** → 改成「今天还剩 67834 分，贵不贵？」→ 点「试听这句」应念出这段（数字念成中文）
9e. **设置分类**：右键 → 设置 → 应有**通用设置 / 聊天设置 / 声音设置**三项：通用里能改通道·模型·额度·网关·身份牌·桌宠（大小/称呼/监控…）；声音里**只有声音**（语音播报 + 音效 + 语音闲聊）；聊天里是人设·常用语·表情包入口 + 聊天行为与会话。顺手试一下聊天里的「双击桌宠：就地输入框」关掉 → 双击应不再弹输入框
9g. **弹窗回退**：右键 → 聊天设置 → 点「角色设定…」进二级 → 左下角应出现「← 返回」；连点可逐级退回（栈深多级都行）；点 ✕ 全关后再开，应没有残留的上一级
9f. **弹窗风格**：随便开几个弹窗（通用设置 / 声音设置 / 常用语）→ 应有统一的分组小标题（左侧蓝条）与间距；把助手窗口拉窄到 500px 左右 → 弹窗应铺满且内容不出格
9e. **按语境挑表情**：跟它聊点带情绪的（夸它 / 吐槽它 / 问傻问题 / 说加班累）→ 它应该**情绪对得上时才插表情**（道谢配害羞捂脸、被吐槽配无语斜眼、加班配打工搬砖…）；也可以直接发 `[stick:害羞捂脸]` 看能不能出图
9d. **弹窗控件**：打开「修改桌宠模型」→ 每张卡片的「移除 / 彻底删除」应**在同一行、靠右**（不再竖排错位），描述最多两行；「导入模型包」那一行应是**按钮 + 文件名**（不再是原生灰色「选择文件」）；设置里的**大小滑块**应是有轨道与圆钮的样式；拖气泡面板标题栏时面板应"提起来"（半透明 + 大阴影）
10. 断开助手（关掉服务）→ 明确提示「助手不在线」并回落模拟模式

## 六、版本

完整演进见 `CHANGELOG.md`。4.0 是一个"收拾干净"的正式版：把 3.x 里散落的功能收敛成
**统一的菜单分栏、统一的设置面板、统一的台词/AI 入口**，并补齐了桌面宿主的兼容坑
（素材路径、皮肤定位、贴纸尺寸、菜单边界）。
4.1 加了**自定义动图皮肤**（上传 GIF/动画 WebP 即会动 + 空闲小动作）、精灵图 PNG→WebP 瘦身
（安装包 -26%），并修了实测反馈的 4 个问题（装死台词贴纸、语音数字朗读、气泡聊天面板悬空、发送行间距）。
4.2 支持**直接上传 zip 模型包**（网上下载的桌宠包多是这个形式）：解析出里面的图片清单，点一张就穿上。
4.3 让模型包**整套搬进来**：`tools/import-petpack.mjs` 把 dsh-pet 包（114 个动作 + 交互配置）整合成
「动作包」皮肤（点击/拖动/余额/随机表演都有动作，素材 6.5MB），并把对话产出的**文件路径渲染成成果卡片**。
4.4 成果卡片升级为「**点一下打开文件** + 打开文件夹位置」（走宿主交付接口），交付约定不再每轮重发，
并给语音提速（数字口语简读「六点八万」、停顿收紧、默认语速微调）。
4.7 桌宠会**自己走两步**：每隔几分钟（±抖动）溜达一次，走走停停 / 逛桌面两种模式、速度三档，
走过去播动作包的行走动作、向右走镜像，被拖被戳立刻停。
