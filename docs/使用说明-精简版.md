# 大肥鱼桌宠 · 使用说明（精简版）

**pet-buddy v5.1.0** —— 一只挂在助手窗口里的桌宠：会看余额、会陪你聊天、会念出来、还会自己溜达。

---

## 一、装上它（10 秒）

| 拿到的是 | 怎么做 |
|---|---|
| `一键安装-pet-buddy-v5.1.0.cmd`（单个文件） | **双击** → 装完提示"按 F5" |
| `pet-buddy-v5.1.0-一键安装.zip` | **解压 → 双击 `安装.cmd`** |

装完切到助手窗口按 **F5**，桌宠出现在右下角。安装器会自动找位置、**先备份旧版**；不需要管理员权限、不用联网。

> 不想要了：双击同一目录里的 `卸载.cmd`（或把 `%TEMP%\pet-buddy-backup-*\` 里的旧版拷回去）。

## 二、四个基本操作

| 操作 | 效果 |
|---|---|
| **单击**桌宠 | 说一句台词 + **报余额**（剩余额度、今日消耗） |
| **双击**桌宠 | 就地弹输入框，直接聊天（回车发送） |
| **右键**桌宠 | 主菜单：气泡聊天 / bibo语音与音效（栏内分「语音」「音效」两组）/ 桌宠 / 设置 |
| **拖动**桌宠 | 随便拖，靠近屏幕边缘会自动吸附；位置记住 |

- 想藏起来：右键 → 桌宠 → **隐藏桌宠**；想找回来点桌面角落的小鱼图标 🐟。
- 位置乱了：右键 → 桌宠 → **位置重置**。
- 大小不合适：右键 → 桌宠 → **大小**（点一下换一档），或到「桌宠设置」里拉滑块（40–200px）。

## 三、主要功能

### 🐟 桌宠形象
- 内置两个模型：**官方精灵图**（全动作动画）与**完整动作包**（114 个动作：点击、拖动、余额、
  吃月饼/放烟花/装点圣诞树等 80 个随机表演）。
- **自己上传**：右键 → 修改模型 → 上传 **GIF / 动画 WebP / 普通图片**，甚至直接丢一个 **zip 包**
  （会列出包里的图让你挑）——上传的动图会自己动。

### 💬 聊天
- **气泡聊天面板**：贴着桌宠头顶的圆角面板，可拖动；**双击聊过的内容也会出现在面板里**（同一份记录）。
- **表情**：输入行左边的 **😊** 打开表情面板——内置 **67 张**（大肥鱼 / 微信表情 / 模型包 memes），
  点一张直接发；「我的」里能批量加自己的图（也支持 zip），还能导出成包。
- **成果卡片**：如果助手在对话里产出了文件（折线图、表格、文档…），回复下面会出现卡片——
  **点一下直接打开文件**，或「定位」到文件夹。
- 想让桌宠发表情，直接发中文名就行：`[stick:害羞捂脸]`、`[stick:可爱]`。

### 🔊 语音
- 聊天回复**自动念出来**（可在「声音设置」关）。
- 三种朗读模式：**语调引导**（经典音色 + 按真人语调选音）/ **经典合成** / **普通朗读**（真人声）。
- 数字会念成中文（67834 → "六点八万"）；标点停顿明显。
- 「试听文本」可以改成你想听的任何句子。
- **语音闲聊**：按住 **右 Alt + M** 说话，松开即发（本地离线识别，不用联网）。
  > 左 Alt 是助手自带的听写，本插件不占用。

### 🚶 自己走动
- 默认每 3 分钟（带随机抖动）自己起来走两步，起步有节奏：**先原地踏步 → 1 秒加速 → 匀速走 → 收住**。
- 模式可选：**走走停停**（原地附近水平溜达）/ **逛桌面**（换个位置）/ **不自己动**；速度三档。
- 你一动它（拖它/戳它）它立刻停下，不打扰你。
- 位置：右键 → 桌宠 → **自行移动设置…**，里面可以「现在就走两步」立刻试。

### 🎛 设置分四处（右键 → 设置）
| 弹窗 | 管什么 |
|---|---|
| **通用设置** | 聊天通道、模型、剩余额度、网关/身份牌（一般不用动） |
| **聊天设置** | 角色人设、台词与开场白、常用语、表情包管理、聊天行为（双击输入框 / 记录互通 / 面板保留条数）、会话 |
| **声音设置** | 语音播报（模式/音色/音量/语速/上限/试听）、音效、语音闲聊入口 |
| **桌宠设置** | 我的称呼、大小、互动形变、键鼠监控、余额格式、开场白，以及自行移动 |

- 二级弹窗左下角有「**← 返回**」可以逐级退回。
- **人设与台词可以让 AI 生成**：聊天设置 → 角色设定 / 台词与开场白 → 「AI 按人设生成」，
  还能设置每天/每周自动更新一次（它会照着你们的聊天记录更新口吻）。

## 四、常见问题

| 情况 | 怎么办 |
|---|---|
| 桌宠不见了 | 点桌面角落的小鱼 🐟 图标（隐藏时会出现）；或重新按 F5 |
| 听不到声音 | 浏览器策略要求先"点一下页面"：**点一下桌宠**即可解锁音频 |
| 余额数字不对 | 单击报的余额取自助手内部额度通道；也可在「通用设置 → 剩余额度」自己填一个数 |
| 表情发了没显示 | 名字要对得上：在表情面板里点一下会复制标记，粘到聊天里即可 |
| 想换个形象 | 右键 → 修改模型 → 上传（GIF 会动，图片也行；静态 ≤2MB、动图 ≤4MB） |
| 更新了新版本 | 双击新的安装器即可覆盖（自动备份旧版），按 F5 生效 |

## 五、它不会做什么

- **不联网也能用**：没有第三方依赖，素材都在本机；语音识别走助手的本地组件。
- **不改你的其它设置**：卸载/回滚只影响这个插件目录。
- 上传的图片、表情、设置都只存在本机（`localStorage`），不会上传到任何地方。
